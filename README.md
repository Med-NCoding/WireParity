# WireParity

Differential testing tool for multi-language API SDKs.

## Overview

WireParity verifies that SDKs generated across different programming languages (Python, TypeScript, Go, Java, etc.) emit semantically equivalent HTTP wire requests for identical logical inputs.

## Development

```bash
# Install dependencies
pnpm install

# Run type checks
pnpm typecheck

# Run test suite
pnpm test
```
